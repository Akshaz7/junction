# GOTCHAS

- 24 GB memory: heavy jobs go through `scripts/heavy.sh` (max 2 at once). No training on the Mac; fine-tune on Modal.
- IfcConvert drops IfcSpace and IfcOpeningElement unless explicitly included.
- GLB holds no names, types or storeys; those come from the IFC via `elements.json`.
- IFC GlobalIds are not valid USD prim names: use `usd_name = "i_" + sha1(item_id)[:16]`.
- Index build must reuse the GLB node boxes, not a second geometry pass.
- `ultralytics` and `PyMuPDF` are AGPL: do not use. Use pypdfium2 + pdfminer.six; RT-DETR or YOLOX.
- ND-licensed models/files (duplex_arc, Dental Clinic) must not be published. hitos_arc is GPL data: do not redistribute.
- `questions.jsonl` has Finnish copies of many questions: filter for English.
- Vercel cannot hold WebSockets: live sync lives on the Aiven Runtime backend.
- AR does not run in the iOS simulator: AR tests are unit tests on the scene; real AR needs the iPhone.
- No `python3.12` on PATH by default: use `uv run --python 3.12` (uv-managed 3.12.14 installed).
- Simulator: no devices existed; LEAD created "Hologram iPhone" (iPhone 16 Pro, iOS 26.1). Codex's sandbox cannot reach CoreSimulator, so IOS runs build-for-testing and the LEAD runs `xcodebuild test`.
- Playwright/Chrome cannot launch inside the Codex sandbox (SIGABRT/EPERM). Codex workers write e2e tests; the LEAD runs them outside the sandbox.
- Runware is NOT OpenAI-compatible: it uses its own task API (`textInference`, `audioInference`) at https://api.runware.ai/v1. Dedicated adapter in engine/models/providers.py.
- `.env` has empty values like `DATABASE_URL=`: `os.environ.get(k, default)` returns "" — use `os.environ.get(k) or default`.
- While `uv sync` (torch) runs, every `uv run` blocks on the venv lock. Test small things with `uv run --no-project --with <pkgs>`.
- Production API image installs only API deps (no torch/ifcopenshell): keep heavy imports out of the engine's API path or update deploy/Dockerfile.
- ENGINE's costs.jsonl records must keep fields `provider`, `task`, `cost_usd` — /api/costs aggregates on them.
- A module-level asyncio.Event binds to the first event loop that uses it; each TestClient has its own loop. Create such objects in the lifespan start.
- IfcConvert waits on stdin if the output file already exists: delete it first and pass stdin=DEVNULL.
- IfcConvert: `--exclude entities IfcOpeningElement` (before `-j`) overrides the default that drops IfcSpace, so rooms are kept.
- scene.json `publishable: false` marks duplex, clinic and hitos: never upload or deploy those scenes.
- Nemotron 3.5 is a reasoning model: send chat_template_kwargs {enable_thinking:false} via the task's extra_body or it burns ~340 tokens and truncates.
- DWG has no converter on the Mac: the 20 opening_design DWG docs have no page images.
- trimesh splits multi-primitive GLB nodes into `<guid>_<hash>`: map back to the GUID before matching item_ids.
- Raster scale: most cubicasa plans have no dimension text: scale falls back to the door-width prior (conf 0.3), so area answers there must be low-confidence or abstain.
- `uv run` can block for minutes on the uv lock while another process syncs: use `uv run --no-sync` (or `.venv/bin/python`) in workers.
- Aiven Runtime builds from a GitHub repo via the Aiven GitHub App (no registry images), deploys are manual ("Deploy latest commit"), HTTP on 443 only; WebSocket support undocumented.
- `localhost:5173` (make dev) shows the live working tree and can be broken mid-edit by Codex; `localhost:4173` serves the last commit (git worktree in scratchpad + vite preview) for Ash to look at. LEAD rebuilds it after web commits.
- Without scipy, trimesh GLB export fails on face colours (scipy now added; older code sets vertex_colors/normals by hand).
- usdchecker is /usr/bin/usdchecker (not in usd-core). UsdPrimvarReader_float2.varname must be typed string, not token.
- Only Gemini accepts audio input among our providers: speech-intent falls back to device speech without GEMINI_API_KEY.
- Running server/tests and engine/tests in ONE pytest process fails 5 engine tests: server tests load .env into os.environ and real keys leak into fake-provider defaults. Being fixed; until then run them separately.
- Revisions renumber positional item ids (removing a wall renumbers later walls): the changes engine must match by geometry, not id.
- e2e/viewer.spec.ts is timing-sensitive under heavy load (failed once in a 12-test batch at load average ~20, passes alone 2/2). WEB should harden waits during W-18.
- Finlex statute pages carry the text inside Next.js script data: don't strip <script> when validating quotes. "1500" and "1 500" (thin space) both occur.
- IFC door type names in ac20 are German (e.g. "IFC Tür - Eine Öffnunsgrichtung", typo as in the model): keep verbatim.
- Held-out (full): 5,953 docs; CubiCasa5K: 4,787 held out, 213 clean (data/sets/cubicasa_clean_ids.txt).
- Rebuilding derived files: `uv run` wrapped in heavy.sh silently did nothing twice (stale 03:35 GLB/USDZ). Always check output mtimes after a rebuild; `PYTHONPATH=. .venv/bin/python -m pipeline.<x>` works.
