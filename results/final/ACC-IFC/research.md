# ACC-IFC source checks

- [Requested buildingSMART IFC4 IfcStair page](https://standards.buildingsmart.org/IFC/RELEASE/IFC4/FINAL/HTML/schema/ifcsharedbldgelements/lexical/ifcstair.htm): curl returned HTTP 403; this URL could not be read and is not cited as verified support. The [official buildingSMART source repository](https://raw.githubusercontent.com/buildingSMART/IFC4.3.x-development/master/docs/schemas/shared/IfcSharedBldgElements/Entities/IfcStair.md) returned HTTP 200 and confirms assembly-versus-undecomposed stair representations and aggregate relationships to flights/landings. We follow actual parent links; schema regressions cover IFC2x3, IFC4 and IFC4x3, including independent flights and nested stairs.
- [IfcOpenShell element utilities](https://docs.ifcopenshell.org/autoapi/ifcopenshell/util/element/index.html): curl returned HTTP 200. `get_aggregate` returns an aggregate parent; `get_decomposition` includes a broader set of descendants, including openings and fills. We therefore exclude related components of the same product family, preserving distinct products such as a door in a wall. Across 12 real files, 33 native counts exactly matched independently walked source relationships and their cited IDs; 15 questions honestly remained unavailable because classification was insufficient.
- [ForensicBIM quantity check](https://forensicbim.business/help/quantity-check/): curl returned HTTP 200. It supports comparing declared quantities with independently measured geometry and distinguishing unit/convention differences from missing evidence. It uses **5% for areas**, where our comparison policy uses **2%**. We implement the requested 2% difference relative to measured footprint, preserving both measurements and the flag in the calculation trace. Of 244 spaces in four room-bearing development files, 236 footprints were measured, eight were unavailable, and all 126 simple profiles with an independent shoelace reference matched.

No empirical symbol thresholds were introduced. Observed distributions and file provenance are in `constants.json`; the distributions do not choose code paths. Sources were fetched on 15 November 2026.

The room-bearing files represent KIT FZK, BIMSpeed Warmond and BSC Duplex origins. Agreement with stored quantities is a cross-check, not independent ground truth. Different net-area conventions can legitimately differ from a geometric footprint. Eight missing geometries produce an explicit partial result and an Estimate label; no bounding-box room area is invented.

In our integration validation, the AC20 source contains 82 GrossFloorArea quantities totalling 2,266.66 m² and 82 NetFloorArea quantities totalling 1,939.3839474444 m². All 82 measured space footprints match the gross quantities. We therefore preserve gross for unqualified scalar floor totals and explicit gross requests; named-room, net and existing net breakdowns retain the declared net convention when the mesh demonstrably represents gross extent. Other net measurements and missing-quantity cases continue to use geometry. Differences over 2% remain visible, without calling a gross footprint a usable net measurement. The source audit and calculation replay are in `round2/demo-source-audit.json`. No existing numeric IFC expectations were changed.

The integration checks cover four development files from three source groups and a newly reserved blind file. Converted room triangles provide 186 footprints across the two room-bearing development files; all 186 available source-geometry comparisons are within the 2% comparison policy. We reuse this scene geometry with the property-only IFC reader, avoiding another full source geometry load. Synthetic tests cover holes, overlapping floor/ceiling projections, node transforms and three IFC schemas. The fake-provider sample200 run preserves all 148 correct answers with zero correct-to-wrong transitions.
